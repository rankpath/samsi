## 1. `colour-skill/` — สกิลสร้างระบบสี

วิธีทำงานคือ อ่านโจทย์ → ตั้งสีพื้นก่อน → ใส่สีหลักหนึ่งสี → พิสูจน์คอนทราสต์ → ส่งมอบ
ผลลัพธ์เป็นโทเคน 12 ตัวที่ตั้งชื่อตามหน้าที่ ไม่ใช่ตามสี

| ไฟล์ | เนื้อหา |
|---|---|
| `SKILL.md` | วิธีการหลัก กฎการใช้โทเคน และจุดที่มักพลาด |
| `references/trend-2027.md` | เทรนด์สี 2026–27 ค่าสีโดยประมาณ และวิธีแปลงมาใช้บนหน้าจอ |
| `references/category-palettes.md` | พาเลตต์พร้อมใช้ 18 หมวดธุรกิจ ค่าคอนทราสต์คำนวณจริงทุกตัว |
| `references/thai-typography.md` | กฎไทป์ไทยและการทำเว็บสองภาษา |

**สาระสำคัญของเทรนด์** Pantone เลือกสีขาวนวล Cloud Dancer เป็นสีแห่งปี 2026
และ WGSN เลือก Luminous Blue เป็นสีแห่งปี 2027 แปลว่าทิศทางคือพื้นเรียบเงียบ
บวกสีหลักสดหนึ่งสี ซึ่งบังเอิญเป็นโครงสร้างของอินเทอร์เฟซที่ดีอยู่แล้ว

## 2. `color-pattern/` — สกิลสร้างลายไร้รอยต่อ

`scripts/patterns.py` สร้างลาย SVG ที่ต่อกันสนิท 13 แบบจากพาเลตต์ที่ให้

```bash
python3 scripts/patterns.py --palette "#F0EEE9,#1E3FCB,#EBB13C" --out ./out
```

`references/tiling.md` เก็บบทเรียนจากตอนทดสอบ เช่น ระยะห่างลายต้องหารขนาดไทล์ลงตัว
รอบสีต้องตรงกับรอบเรขาคณิต และการไล่ระดับในไทล์จะเกิดแถบเสมอ

ตัวอย่างผลลัพธ์อยู่ใน `pattern-demo/index.html`

**กฎที่กลับด้านกับสกิลสี** ลายที่อยู่หลังตัวหนังสือต้องต่างจากพื้นแค่ประมาณ 1.3:1
ถ้าอ่านลายออก แปลว่าอ่านตัวหนังสือไม่ออก

## 3. `samsi-logos/` — แบรนด์ Samsi

ชื่อมาจากแมวสามสี แนวคิดคือสองสีทับกันเกิดสีที่สาม

- `v2/` — **โลโก้ปัจจุบัน** ไอคอนหน้าต่างเบราว์เซอร์ ไฟล์ PNG 5 ไฟล์ที่ได้รับมา กับไฟล์ขนาดเว็บ และคู่มือใน `v2/README.md`
- `retired-cat-v1/` — โลโก้หัวแมวเดิม (เลิกใช้แล้ว เก็บไว้อ้างอิง) 17 SVG 17 PNG ไอคอน 8 ขนาด และ `logo-usage.md`
- `index.html` — แบบร่างโลโก้เดิม 36 แบบ ชุดเรขาคณิต 20 แบบ ชุดแมว 16 แบบ (ของโลโก้หัวแมว)
- `23-colourways.html` — คู่สี 24 คู่สำหรับแบบร่างโลโก้เดิม

**สีแบรนด์ (วัดจากโลโก้ v2)** Forest `#022A1A` Cream `#FEF6EA` Blue `#0246EE` Coral `#FE7E52`
ตั้งเป็นสีมาตรฐานเมื่อ 21 ต.ค. 2026 ธีม Samsi บนเว็บดึงสีจากชุดนี้ รายละเอียดและค่าคอนทราสต์อยู่ใน `v2/README.md`

ไม่ทราบชื่อฟอนต์ของตัวอักษรในโลโก้ใหม่ และชุดนี้ไม่มีไฟล์เวกเตอร์
ส่วนสีและฟอนต์ของโลโก้หัวแมวเดิม (Coral `#E9654B` Forest `#1E3A2C` Outfit SemiBold) อยู่ใน `retired-cat-v1/logo-usage.md`

## 4. เว็บ Samsi

- `samsi-landing-th-en.html` — ไฟล์ master ไฟล์เดียวจบ มีปุ่มสลับภาษาในตัว ใช้พรีวิว
- `site/th/` และ `site/en/` — หน้าแยกภาษาสำหรับอัปขึ้นเว็บจริง
- `site/build-th-en.py` — สคริปต์สร้างสองหน้านั้นจากไฟล์ master

แก้เนื้อหาที่ไฟล์ master แล้วรันสคริปต์ใหม่ สองหน้าจะไม่หลุดจากกัน

**ก่อนอัปขึ้นเว็บจริง** เปิด `site/build-th-en.py` แก้ค่า `DOMAIN` จาก `example.com`
เป็นโดเมนจริง แล้วรันใหม่ ค่านี้ไปอยู่ใน canonical และ hreflang ซึ่งถ้าผิดจะแย่กว่าไม่ใส่

## 5. `logistics-saas/` — ตัวอย่างการใช้ Colour Skill จริง

ระบบสีสำหรับแอป SaaS โลจิสติกส์ พร้อมหน้าพรีวิวที่สลับได้ทั้งภาษาและโหมดมืด

จุดสำคัญคือโลจิสติกส์ต้องการ *ระดับสถานะ* ห้าระดับ ไม่ใช่แค่คู่สำเร็จกับผิดพลาด
และทุกชิปสถานะมีสัญลักษณ์กำกับ ไม่ได้ใช้แค่สี เพราะคู่ล่าช้ากับมีปัญหาคือคู่ที่
คนตาบอดสีแดงเขียวแยกไม่ออก

ตรวจคอนทราสต์ครบสี่โหมด ไทย-อังกฤษ คูณ สว่าง-มืด ผ่านทุกคู่

## สิ่งที่ยังค้าง

1. แก้ `DOMAIN` ในสคริปต์ build ก่อนอัปเว็บ
2. ยังไม่ได้ลองเอา `colour-skill` ไปใช้กับงานลูกค้าจริงสักงาน
3. ถ้าจะพิมพ์จริง ต้องให้โรงพิมพ์แปลง CMYK ด้วยโปรไฟล์กระดาษและขอปรู๊ฟก่อน
   โดยเฉพาะสีคอรัลซึ่งสดเกินกว่าหมึก CMYK ทั่วไปจะทำได้เต็มที่
