## สีที่วัดจากไฟล์

วัดจากไฟล์แนวตั้ง ซึ่งมีพื้นที่สีใหญ่ที่สุด

| บทบาท | Hex |
|---|---|
| กรอบและตัวอักษร (Forest) | `#022A1A` |
| แผงซ้าย (Cream) | `#FEF6EA` |
| แผงขวา (Blue) | `#0246EE` |
| สี่เหลี่ยมตรงที่ทับ (Coral) | `#FE7E52` |

ไฟล์แต่ละไฟล์สีไม่ตรงกันเป๊ะ ไฟล์แนวนอนเข้มกว่าเล็กน้อย
(Forest `#022212`, Blue `#023ED2`) จึงใช้ค่าจากไฟล์แนวตั้งข้างบนเป็นมาตรฐาน (ดูหัวข้อถัดไป)
และควรให้นักออกแบบทำเวกเตอร์ใหม่ด้วยสี 4 ค่านี้

## สีมาตรฐานและสีบนเว็บ

ตั้งสีของโลโก้ใหม่ 4 สีเป็นมาตรฐานเมื่อ 21 ต.ค. 2026 คือ Forest, Cream, Blue และ Coral ตามตารางข้างบน

ธีม Samsi บนเว็บดึงสีจากชุดนี้ ดังนี้

| โทเคน | Hex | ที่มา |
|---|---|---|
| พื้นหลัง | `#FEF6EA` | Cream |
| พื้นยกระดับ | `#FFFFFF` | ขาว |
| พื้นลึก | `#F1EADE` | Cream เข้มขึ้น 5% |
| เส้นขอบ | `#E0D8CE` | Cream เข้มขึ้น 12% |
| ตัวอักษร | `#022A1A` | Forest |
| ตัวอักษรรอง | `#395748` | ผสม Forest 78% กับ Cream 22% ได้ 7.44:1 บนพื้นหลัง |
| สีหลัก | `#E8603E` | Coral ที่ลดความสว่างลง ได้ 3.17:1 บนพื้นหลัง |
| สีหลักแบบจาง | `#FADECE` | สีหลักผสม Cream |

สีหลักบนเว็บไม่ใช่ `#FE7E52` ตรง ๆ เพราะ Coral ของโลโก้บน Cream ได้แค่ 2.35:1
ไม่ผ่านเกณฑ์ขอบ 3:1 ที่หน้า Home ของ Samsi ใช้ตรวจ Coral ตัวเดิมยังใช้ได้กับโลโก้และกราฟิกขนาดใหญ่

ยังไม่ได้ตัดสินใจ: Blue จะเป็นสีรองในหน้าเว็บหรือไม่ ตอนนี้ Blue อยู่ในโลโก้เท่านั้น

## ค่าคอนทราสต์ที่คำนวณแล้ว (WCAG)

| คู่สี | ค่า | ผล |
|---|---|---|
| Forest บน Cream | 14.52:1 | ผ่าน |
| White บน Blue | 6.75:1 | ผ่าน |
| Cream บน Blue | 6.29:1 | ผ่าน |
| Blue บน Cream | 6.29:1 | ผ่าน |
| Forest บน Coral | 6.17:1 | ผ่าน |
| Coral บน Forest | 6.17:1 | ผ่าน |
| White บน Coral | 2.52:1 | ไม่ผ่าน |
| Coral บน Cream | 2.35:1 | ไม่ผ่าน |
| Blue บน Forest | 2.31:1 | ไม่ผ่าน |

ปุ่มสี Coral ใช้ตัวอักษร Forest ไม่ใช้ตัวอักษรขาว และไม่ใช้ Coral เป็นสีตัวอักษรบนพื้นครีม

## ข้อจำกัดของชุดนี้

- มีแต่ PNG ไม่มี SVG ย่อขยายมาก ๆ หรือพิมพ์ขนาดใหญ่ต้องให้นักออกแบบวาดเวกเตอร์ใหม่
- ไฟล์ขาวดำมีเส้นกรอบบางด้านในที่ไม่มีในไฟล์สี ควรดูให้แน่ใจก่อนใช้พิมพ์
- ไม่ทราบชื่อฟอนต์ของตัวอักษร Samsi ในโลโก้ เว็บยังพิมพ์คำว่า Samsi ด้วย Bricolage Grotesque
  ข้างไอคอนใหม่ ซึ่งหน้าตาไม่เหมือนตัวอักษรในโลโก้
- กรอบ Forest กลืนไปกับพื้นมืดมาก ไอคอนยังอ่านออกจากแผงสีด้านใน ตรวจแล้วบนธีม Nightfall และ Terminal

  ใช้ที่ 16 เฉพาะ favicon
